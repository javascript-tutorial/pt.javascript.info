# O Tutorial de JavaScript Moderno

Este repositório aloja o conteúdo em português do Tutorial Moderno de JavaScript, publicado em [https://javascript.info](https://javascript.info).

## Traduções

Gostaríamos de disponibilizar o tutorial em vários idiomas. Por favor, ajuda-nos a traduzir.

Acede a <https://javascript.info/translate> para mais detalhes.

## Contribuições

Também gostaríamos de colaborar no tutorial com outras pessoas.

Há algo de errado? Falta algum tema? Explica-o às pessoas, adiciona-o como PR 👏

**Podes editar o texto em qualquer editor.** O tutorial usa um formato "markdown" aprimorado, fácil de entender. E se quiseres ver como fica no site, há um servidor para executar o tutorial localmente em <https://github.com/javascript-tutorial/server>.

A lista de contribuidores está disponível em <https://javascript.info/about#contributors>.

Para saberes como contribuir, lê o nosso [Guia de Contribuição](/CONTRIBUTING.md)

## Estrutura

Cada capítulo, artigo ou tarefa tem a sua própria pasta.

A pasta encontra-se nomeada como `N-url`, onde `N` é um número para efeitos de ordenação e `URL` é a parte do URL com o título do conteúdo.

O tipo de conteúdo é definido pelo ficheiro dentro da pasta:

- `index.md` corresponde a um capítulo
- `article.md` corresponde a um artigo
- `task.md` corresponde a uma tarefa (a solução também deve ser fornecida no arquivo `solution.md`)

Cada um destes ficheiros começa com um `# Cabeçalho principal`.

É muito fácil adicionar algo novo.
