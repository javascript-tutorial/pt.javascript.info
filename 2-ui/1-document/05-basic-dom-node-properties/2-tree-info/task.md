# Contar descendentes

Há uma árvore estruturada como `ul/li` aninhados.

Escreva o código que, para cada `<li>`, mostra:

1. Qual é o texto dentro dele (sem a subárvore)
2. O número de `<li>` aninhados -- todos os descendentes, incluindo os mais profundamente aninhados.
