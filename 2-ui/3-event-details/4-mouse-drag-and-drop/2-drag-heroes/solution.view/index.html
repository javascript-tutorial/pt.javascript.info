Posicione os super-heróis pelo campo de futebol.

Os super-heróis e a bola são elementos com a classe "draggable". Torne-os realmente arrastáveis.

Importante: limite o arrasto pela janela. Se um arrastável alcançar o topo ou o fundo da janela, então a página deve rolar para nos deixar continuar arrastando.

Se sua tela for grande o suficiente para caber o documento inteiro -- diminua a janela para ter rolagem vertical, para que você possa testar isso.

Nessa tarefa é suficiente tratar a rolagem vertical. Geralmente não há rolagem horizontal, e ela é tratada de forma parecida se necessário.

E mais uma coisa: os heróis nunca podem deixar a página. Se eles alcançarem a borda do documento, sem arrasto para fora dela.
