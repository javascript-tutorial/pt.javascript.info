# Relógio estendido

Temos uma classe `Clock`. Por enquanto, ela imprime a hora a cada segundo.


[js src="source.view/clock.js"]

Crie uma nova classe `ExtendedClock` que herda de `Clock` e adiciona o parâmetro `precision` -- o número de `ms` entre os "tiques". Deve ser `1000` (1 segundo) por padrão.

- Seu código deve estar no arquivo `extended-clock.js`
- Não modifique o `clock.js` original. Estenda-o.
